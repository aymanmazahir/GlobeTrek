GlobeTrek - demo travel booking skeleton

How to use:
- Place this folder under your web server root (example: C:\inetpub\wwwroot\ or Apache htdocs)
- Create a MySQL database named `globetrek` and import `database/globetrek.sql`
- Set environment variables DB_HOST, DB_NAME, DB_USER, DB_PASS or edit `includes/db.php`
- Open `/globetrek/pages/index.php` in your browser

Notes:
- This is a minimal starter. Implement real authentication, validation, and payment gateway before production.
